
# TutorHelper — Beta Releases

**Welcome to the TutorHelper Beta Testing Programme!**

Thank you for helping us test TutorHelper, a collection of WordPress plugins designed to make managing private tuition, bookings, students and online learning easier.

This repository provides downloadable beta versions of the TutorHelper plugins.

As a beta tester, you'll receive a **complimentary 12-month licence for all TutorHelper Pro features**, allowing you to explore the full functionality while helping us improve the software.

> **Important:** These are beta releases. Although we test each version before release, you may encounter bugs or features that are still being developed. We recommend testing on a staging website wherever possible and taking a full backup before installing or updating.

---

## 1. Available plugins

The plugins are organised into four folders.

### 📁 01_TutorHelper Core Plugins

**TutorHelper Bookings — Core**

The main TutorHelper plugin, providing the foundation for managing students, tuition bookings and lesson administration.

**Install this plugin first.**

The Core plugin is required for all other TutorHelper plugins.

### 📁 02_Bookings Pro (required for all pro plugins)

**TutorHelper Pro**

Extends TutorHelper Bookings with additional functionality for professional tutors.

TutorHelper Pro must be installed and activated before installing Pro add-ons or LMS Premium.

A valid licence key is required to unlock Pro functionality.

### 📁 03_Bookings Pro Add-Ons

Optional extensions for TutorHelper Bookings and Pro.

| Plugin | Function |
|---|---|
| **TutorHelper Group Bookings** | Manage group tuition sessions and bookings. |
| **TutorHelper Parent/Child** | Link parent and student accounts, with dedicated parent dashboard functionality. |
| **TutorHelper Agency** | Additional tools for tuition agencies managing multiple tutors and students. |

Install only the add-ons you wish to test.

These add-ons require TutorHelper Bookings Core and TutorHelper Pro to be active.

### 📁 04_TutorHelper LMS

**TutorHelper LMS — Core**

Adds online learning functionality, including Courses, Topics, Lessons, reusable Questions and Quizzes.

Requires TutorHelper Bookings Core.

**TutorHelper LMS — Premium**

Unlocks additional learning and assessment features, including premium Question types, homework submissions, marking and advanced Quiz functionality.

Requires TutorHelper LMS Core, TutorHelper Bookings Core and TutorHelper Pro.

A valid licence is required for Premium functionality.

## 2. Installation order

**Please install the plugins in the following order.**

| Order | Plugin | Required? |
|---|---|---|
| 1 | TutorHelper Bookings Core | Yes — always install first |
| 2 | TutorHelper Pro | Required for Pro features and add-ons |
| 3 | TutorHelper Group Bookings | Optional |
| 4 | TutorHelper Parent/Child | Optional |
| 5 | TutorHelper Agency | Optional |
| 6 | TutorHelper LMS Core | Required for LMS functionality |
| 7 | TutorHelper LMS Premium | Optional — requires LMS Core and Bookings Pro |

You do not have to install every plugin.

For example:

- **Bookings only:** Install TutorHelper Bookings Core.
- **Bookings with advanced features:** Install Bookings Core and Pro.
- **Bookings with parent dashboards:** Install Bookings Core, Pro and Parent/Child.
- **Online learning:** Install Bookings Core and LMS Core.
- **Full LMS functionality:** Install Bookings Core, Pro, LMS Core and LMS Premium.

**Always activate the required Core plugins before activating their Premium extensions.**

## 3. How to download and install

### Step 1 — Download the plugin ZIP

1. Open the appropriate folder in this GitHub repository.
2. Find the ZIP file for the plugin you want to install.
3. Click the ZIP filename.
4. Select **Download raw file** (download icon) to save the ZIP to your computer.
5. Keep the file in ZIP format — do not extract it.

**Do not use GitHub's green "Code → Download ZIP" option.** That downloads the repository structure rather than an individual installable plugin.

### Step 2 — Install in WordPress

1. Log in to your WordPress admin dashboard.
2. Navigate to **Plugins → Add New Plugin**.
3. Click **Upload Plugin**.
4. Select the downloaded TutorHelper ZIP.
5. Click **Install Now**.
6. Once installation is complete, click **Activate Plugin**.

Repeat these steps for the other plugins, following the installation order above.

### Step 3 — Activate your Pro licence

If you have installed TutorHelper Pro, LMS Premium or a paid add-on, you will need a licence key.

1. Open the relevant TutorHelper licence or activation settings in WordPress.
2. Enter the licence key provided to you.
3. Save and activate your licence.
4. Confirm that the relevant Premium features are available.

Your beta testing licence provides **12 months of access to all TutorHelper Pro features**.

## 4. Updating an installed plugin

New beta versions will be added to this repository as development progresses.

To update a plugin manually:

1. Download the latest ZIP for that plugin.
2. Back up your WordPress website and database.
3. Navigate to **Plugins → Add New Plugin → Upload Plugin**.
4. Upload the new ZIP.
5. If WordPress recognises an existing installation, select **Replace current with uploaded**.
6. Check that the plugin remains active and that its functionality is working.

**Do not delete an existing plugin simply to update it.** Use WordPress's replacement process where supported.

After updating, check that any dependent plugins are compatible with the new version.

## 5. Testing guidelines

We particularly welcome feedback on:

- Installation and plugin activation.
- Booking and student management.
- Parent and student dashboards.
- Group bookings and agency features.
- Courses, Lessons and learning activities.
- Question creation and Quiz delivery.
- Homework submissions and marking.
- Layout problems on desktop, tablet and mobile.
- Unexpected errors or behaviour.

You don't need to be technically experienced to help us test. Feedback about confusing instructions or features that are difficult to use is just as valuable as identifying a software bug!

### Reporting a problem

Please email **holly@teachallaboutit.uk** with the subject:

**TutorHelper Beta Bug Report**

Where possible, include:

1. **Plugin and version:** Which TutorHelper plugin were you using?
2. **What you were doing:** What steps led to the problem?
3. **What you expected:** What should have happened?
4. **What actually happened:** Describe the issue or error?
5. **Screenshots:** Include screenshots where helpful.
6. **WordPress environment:** Your WordPress and PHP versions, if known.

Please remove student names, personal details, licence keys and other confidential information from screenshots and logs before sharing them.

## 6. Important information for beta testers

### Backups

Please maintain a recent backup of your website and database, especially before updating a beta plugin.

### Student data

TutorHelper may process student information, lesson bookings, assessment submissions and financial records.

Please ensure that your use of the plugin complies with your organisation's data-protection obligations.

Do not share real student data in public GitHub Issues or other publicly accessible reports.

### Plugin dependencies

Some TutorHelper plugins depend on others.

If a Premium feature does not appear, first check that the relevant Core and Pro plugins are active and that your licence has been activated.

### Beta functionality

Some features may change during the testing period. Existing functionality may be refined, renamed or improved in subsequent releases.

### Licence period

Complimentary beta licences are valid for 12 months from their assigned activation or validity date, as specified by the licence issued to you.

The beta licence does not guarantee that every feature will remain unchanged or that beta releases will be free from errors.
